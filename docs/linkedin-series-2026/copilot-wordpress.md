Copilot is the new WordPress : 17 projets, 2 langues, 0 euro.

Soyons honnêtes. Pour un tout petit site perso quasi statique, WordPress a de vrais inconvénients :
1. une base de données à maintenir,
2. une interface un peu désuète, dont les usagers sont rarement satisfaits,
3. une batterie de plugins à maintenir, utiles dans 20 % des cas.

Ma solution : une interface IA pour faire votre site vous-même, à la voix.

Je l'ai fait pour mon vieil ami Mathieu Fiorentini, je le connais depuis la maternelle, je ne pouvais pas refuser.

L'architecture : GitHub Copilot, GitHub Actions, GitHub Pages, Astro JS et Tailwind CSS. Mathieu a rédigé son cahier des charges à l'envie, aidé d'une IA — Claude, Mistral, peu importe.

Et vogue la galère : un portfolio nickel qui fait parfaitement le travail, même avec plusieurs mises à jour par mois. Dès le premier jour, Mathieu a publié la sienne lui-même.

Je vous mets l'article en commentaire, avec le lien vers son portfolio et vers le repo GitHub.

Et vous, combien de plugins maintenez-vous pour trois pages ?
